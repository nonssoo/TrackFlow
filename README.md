# TrackFlow

A full-stack shipment tracking and logistics platform built with Django.
<img width="2835" height="1617" alt="image" src="https://github.com/user-attachments/assets/0f8449b7-8fe0-4695-9fe8-143514e25692" />


## Features
- Role-based access (customer, staff/dispatcher)
- Delivery request → approval → shipment workflow
- Full shipment status history / audit trail
- Public tracking by tracking number
